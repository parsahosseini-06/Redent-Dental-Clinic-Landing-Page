# 04 — User Journey

## Core User Questions

The research identified six questions patients commonly have:

1. Is this clinic trustworthy?
2. Will it hurt?
3. How much will it cost?
4. Which doctor should I choose?
5. How long will treatment take?
6. Is this treatment suitable for me?

---

# User Journey

```text
Search Google
      ↓
Read Reviews
      ↓
Visit Website
      ↓
Learn About Treatments
      ↓
Meet the Doctors
      ↓
See Previous Results
      ↓
Gain Confidence
      ↓
Book Appointment
```

---

# UX Interpretation

Each stage of the journey corresponds to a section or feature.

| User Need | Website Response |
|---|---|
| Discover clinic | Hero / value proposition |
| Understand treatments | Treatment Finder |
| Reduce uncertainty | Your First Visit |
| Evaluate expertise | Doctor Profiles |
| See evidence | Case Studies |
| Understand cost | Cost Estimator |
| Take action | Appointment Booking |
| Resolve objections | FAQ |

---

# Conversion Logic

The website does not ask the user to book immediately.

Instead, it progressively removes uncertainty.

```text
Discover
   ↓
Understand
   ↓
Trust
   ↓
Estimate
   ↓
Personalize
   ↓
Book
```

This sequence informs the architecture of the landing page.
