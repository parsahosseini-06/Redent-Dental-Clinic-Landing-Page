# 08 — Visual Design

## Brand Direction

The brand personality defined during discovery is:

- Professional
- Friendly
- Educational
- Honest
- Calm
- Reassuring

---

# Visual Principles

## Calm

Avoid visual patterns that reinforce medical anxiety.

## Clarity

Use clear hierarchy and predictable navigation.

## Trust

Use structured information, evidence and professional presentation.

## Modernity

Communicate modern dentistry through technology, spacing, interaction and content structure rather than exaggerated visual effects.

---

# Content Tone

The interface should sound:

- Professional
- Friendly
- Educational
- Honest
- Calm
- Reassuring

Avoid:

- Aggressive marketing
- Exaggerated claims
- Fear-based messaging

---

# Visual Hierarchy

The primary hierarchy should prioritize:

1. Value proposition
2. Primary action
3. Treatment understanding
4. Trust evidence
5. Pricing clarity
6. Booking

---

# Interaction Visuals

Interactive elements should communicate state clearly.

Examples:

- Active treatment category
- Active comfort mode
- Selected estimator treatment
- Current booking step
- Selected date/time
- Active case study

---

# Responsive Design

The experience should be adapted for:

- Desktop
- Tablet
- Mobile

Particular attention should be paid to:

- Navigation
- CTA placement
- Touch targets
- Treatment filtering
- Estimator controls
- Booking controls
- Case-study interaction
- Before/after interaction

---

# Accessibility Considerations

Where applicable:

- Maintain sufficient text contrast
- Provide visible focus states
- Use semantic controls
- Avoid relying only on color to communicate state
- Make interactive controls keyboard accessible
- Provide descriptive labels for form controls
- Respect reduced-motion preferences where motion is used
